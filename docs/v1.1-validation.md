## Important integration decisions

Strict v1.1 tier write restrictions require explicit `space_type`. Omitted types
infer their tier while preserving old membership behavior. New four-level document
ACLs enforce their conditions even on owners/admins, including in legacy spaces.
This compatibility distinction is deliberate, not an automatic security migration.

Default ask is keyword + offline extractive, with no external model call. Hosts
may explicitly select hybrid mode and inject a generator. No evidence or a score
below configured `min_score` means zero generator invocations. RRF scores are not
semantic confidence, and free-form plugin output is trusted host code; see design
for quality/attestation limits. No production integration has been performed.
